# 正式临床资料目录

此目录放置真实 SAS7BDAT、ID 对应表及队列成员表。主配置的 clinical.cohorts 明确每个文件、ID列及合并角色。当前尚无真实 SAS；程序会列出未配置字段，不生成临床发现。

variables.xlsx 是用户变量需求表的原样副本，用于人工核对候选字段。它不会被当作患者数据读取，也不进入默认移植包。代码使用已确认的 config 映射读取 SAS。输入规则、多表合并示例、死亡与不可测编码见 ../docs/clinical.md。

每人使用稳定 subject_id 对接258个G/W特征和原始病灶体积。发现与验证必须无患者重叠。NIHSS、mRS与MoCA的正式分析已经实现，真实运行等待文件、死亡编码和MoCA规则确认。禁止将 archive 内合成表指定为正式来源。
