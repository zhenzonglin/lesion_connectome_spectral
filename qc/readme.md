# 方法与健康参考审核

按用户最新要求，本阶段不进行患者病灶质控，不创建患者人工审核表，不输出病灶叠加图。

code_checklist.tsv 是当前完整项目的可编辑代码核查表，按输入、病灶、临床、插补、模型、组合、验证和注释顺序列出函数与参数。详细说明见 docs/code_review.md。checklist.tsv 为此前仅影像阶段的历史表，保持原样，不进入新的默认移植包。reference.png 和 anatomy.png 用于检查健康参考；既有人工记录不覆盖。

空病灶记录在每次运行的 excluded.tsv 和对应患者 record.json，不进入数值分析。计算必需的格式、仿射及重采样一致性检查保留；它们不代表解剖质控。
