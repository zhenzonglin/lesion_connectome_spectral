Note: This repository contains a large number of NIFTI and TRK files that were uploaded using Git Large File Storage (LFS). If you download the repository as a zip file, then it may only contain pointers to these files, and they will appear to be corrupted. Please clone the repository using Git with Git LFS installed and configured. Otherwise, please e-mail me and I will provide a direct download link.
